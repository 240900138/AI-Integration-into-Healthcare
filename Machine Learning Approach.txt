Machine Learning Approach 
Because the dataset contains admission features and a labelled target (the medical condition), supervised machine learning is used in this project. The task is multi-class classification with six classes. The Random Forest Classifier from Scikit-learn, which combines many decision trees to improve predictive performance, is wrapped in a Scikit-learn Pipeline together with its preprocessing so that exactly the same transformations are applied during training, testing and prediction.
Random Forest was chosen because it can:
•	Manage multi-class classification with a mix of categorical and numeric features.
•	Reduce overfitting by averaging the predictions of many trees.
•	Provide feature importance rankings and class probabilities.
•	Work with little tuning and without assumptions about the shape of the data.

To judge whether the Random Forest adds value, it was compared with three alternatives on the same unseen test data: a baseline that always predicts the most common class, Logistic Regression and a Decision Tree. All four models score between 16.30% and 16.63%, which shows that the limitation lies in the data and not in the choice of algorithm. For this reason, more complex algorithms (such as k-Nearest Neighbours, Support Vector Machines or gradient boosting) were not pursued: a more powerful model cannot find a relationship that is not in the data.
